# Bash — администрирование

Ветка объединяет задания по управлению процессами и настройке сетевого соединения виртуальной машины.

## Файлы ветки

### Задание 1 — Администрирование
- [Задание](<Задание 1 - Администрирование.pdf>) — исследовать процессы с помощью `ps`, а также найти нужные параметры и справочные страницы.
- [Решение](<Решение 1 - Администрирование.pdf>) — отчёт с командами для просмотра процессов, сортировки по памяти и поиска справки.

### Задание 2 — Сетевое администрирование
- [Задание](<Задание 2 - Сетевое администрирование.pdf>) — настроить Host-Only адаптер, назначить IP-адрес и проверить связь командой `ping`.
- [Решение](<Решение 2 - Сетевое администрирование.pdf>) — отчёт о настройке интерфейса и проверке связи между хостом и виртуальной машиной.
